# Fiduciary Computation

**Public Research Marker · Doctoral Core v0.1 · 2026-10-01**

Fiduciary Computation (FC) is a doctoral research programme investigating explicit computational boundaries between information and protected consequences.

Its working premise is deliberately narrow: a consequential system should make explicit which declared causes are permitted to affect admission and execution, rather than allowing hidden, retrospective, or undeclared dependencies to acquire consequential authority.

```text
Information
  ≠ Proposal
  ≠ Consequential Admission
  ≠ Consequential Authority
  ≠ Protected Execution
  ≠ Outcome
```

## Public terminology snapshot

- **Fiduciary Computation (FC)** — research programme on explicit computational boundaries for consequential systems.
- **Consequential Admission** — the explicit boundary at which a proposal is evaluated under declared conditions before it may acquire consequential authority.
- **Explicit Causal Boundary** — a boundary through which consequence-changing dependencies must pass before they may legitimately affect a protected consequence.
- **Bounded Trust** — trust dependencies declared and bounded relative to a specific protected consequence.
- **Durable Fiduciary Deed (DFD)** — research term for a durable representation of a constituted consequential act whose identity is distinguished from any particular carrier.
- **Consequential Authority** — bounded authority derived after admission and before protected execution.
